PUBLICAÇÃO NO GITHUB PAGES
1. Crie um repositório chamado: SEU_USUARIO.github.io
2. Faça upload de todos os arquivos mantendo a estrutura.
3. Em Settings > Pages, selecione a branch principal e a pasta / (root).
4. O site será publicado no endereço do seu GitHub Pages.

OBSERVAÇÕES
- O layout já é responsivo para desktop e celular.
- O LinkedIn está apontando para o perfil informado.
- O botão de CV espera o arquivo assets/curriculo-wellington-freitas.pdf.
- Os links "Case em breve" são placeholders para substituir pelos seus projetos reais.
